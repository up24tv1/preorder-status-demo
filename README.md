# PreorderPulse: demo

A preorder status page for small shops. The owner groups orders into batches, moves each batch through stages (confirmed → production → QC → warehouse → shipping → delivered), and posts short notes. Customers look up their order number to see the stage, the latest note and the ETA. The owner gets nudged when a batch has gone 7+ days without an update or is past its ETA.

It is static HTML/JS with localStorage only, no APIs or keys. The sample data is illustrative.

To publish: Settings → Pages → Deploy from branch → main / root.
